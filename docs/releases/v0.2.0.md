# NEXUS v0.2.0 — installed application search

**Status:** historical development milestone, not a claimed accepted public release.
Code date: 2026-11-10. The `v0.2.0` tag identifies
[commit 92cc084](https://github.com/ishanpati/Nexus/commit/92cc084c2985f1f94bfc288d76bbfad4f8b47ff3).
Package metadata at that tag remains **0.1.0**. A tag named v0.2.0 does not imply
that a 0.2.0 installer was built or published.

## What improved

- Search and launch applications registered in Start Menu and Windows AppsFolder,
  including registered desktop and Store apps.
- Match full names, prefixes, words, substrings, and conservative typos. Successful
  launches contribute a small local ranking tie-breaker.
- Recognize apps through cached native icons and refresh the application catalog
  explicitly. Failed refreshes retain the last usable catalog.
- Keep the existing Notepad command, global shortcut, placement, and dismissal behavior.

## Use and installation

Use an app's name in ordinary search and activate the selected result. The target
remains Windows 11 x64 with WebView2; Everything is not required because file
search is introduced in v0.3. No public v0.2.0 installer is advertised here.

## Known limitations and upgrade context

Portable apps outside the Windows catalogs, other users' registrations, and
unsupported shortcuts may be absent; similar-looking entries can remain.
Workflow storage is not part of this milestone. The metadata mismatch should
be considered when identifying old installers; it has not been rewritten.

The tag's README records implementation and selected verification. It does not
establish current installed-app acceptance. See [installation/upgrades](README.md#installation-and-upgrades)
and the [changelog](../../CHANGELOG.md).
