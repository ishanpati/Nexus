# NEXUS v0.1.0 — initial launcher

**Status:** historical development milestone, not a claimed accepted public release.
Code date: 2026-11-10. The `v0.1.0` tag identifies
[commit 4201194](https://github.com/ishanpati/Nexus/commit/420119457c38bed4d0338128ef1edd8446805950),
whose package version is 0.1.0.

## What changed

- A compact floating command bar filters local command names and aliases.
- Open Notepad through keyboard selection or a result click.
- Ctrl+Shift+Space shows or hides the bar; Escape and focus loss dismiss it.
- Showing the bar restores its active-monitor position and input focus. Dragging
  moves it temporarily; single-instance handling reopens the existing process.

## Use and installation

The documented target is Windows 11 x64 with WebView2. No Everything dependency
is needed at this stage: indexed file search does not exist yet. The tag's README
records development/build instructions and selected native window checks.
There is no public v0.1.0 download advertised by these notes.

## Known limitations and upgrade context

This version does not discover installed apps or provide file search, Windows
control commands, or workflows. Physical multi-monitor, other display scales,
installer, and disconnected-network checks were not completed in the tag's README.
Workflow storage was introduced later; current shared-data precautions still
matter if a newer development build has used the same application identifier.
